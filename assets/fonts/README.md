# Locally hosted proposal fonts

Downloaded from Google Fonts on 25 October 2026 for the typography comparison. The WOFF2 files are the Latin subsets returned by the Google Fonts CSS API. No font styles were redrawn or edited.

Families: Manrope; Newsreader (roman and italic); Instrument Sans; Sora; Source Serif 4 (roman and italic).

The Google Fonts distribution's license text for each family is retained in the corresponding `LICENSE-*.txt` file. The public site uses Instrument Sans + Newsreader by default. The other families remain available in the comparison; they load when used by a preview.

Sources:

- https://fonts.google.com/specimen/Manrope
- https://fonts.google.com/specimen/Newsreader
- https://fonts.google.com/specimen/Instrument+Sans
- https://fonts.google.com/specimen/Sora
- https://fonts.google.com/specimen/Source+Serif+4

Original designers' information is linked from the credits in `typography-preview.html` and from `TYPOGRAPHY.md`.

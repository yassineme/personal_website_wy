# User publication rule

All website and CV changes must remain local for the user to modify and review.
The user approves changes and manually pushes/publishes them.
Never deploy, promote, push commits, change live hosting/environment settings,
or run production verification that submits forms as part of ordinary work.
Do not treat a request to change the website as permission to publish it.
Local previews and tests are allowed. Do not change the live site to roll back
an earlier deployment unless the user explicitly requests that live action.

# Website palette

Use the existing website charcoal (`--paper`), ivory (`--ink`) and muted grey
(`--muted`) palette for interface components. Do not introduce green, red or
other accent colours to markets panels, tooltips or quote indicators. Use the
existing directional arrows and labels to distinguish market movement.

# Manual design approval

Use Vercel's Web Interface Guidelines for design reviews instead of Better Design.
Prefer a connected Vercel Design Guidelines MCP when available; otherwise use the
`web-design-guidelines` skill and its official Vercel guideline source.

Preserve the original website font sizes. Do not apply broad typography changes
because a design guideline recommends them. Present subsequent design-review
recommendations individually, with the affected page/component and exact proposed
before/after change, and wait for the user's explicit approval of each one before
implementing it. A review request or guideline finding is not approval to apply
those recommendations automatically.

# Employer confidentiality

Do not publish or repurpose employer work on this website. Public pages, metadata, structured data, assets, feeds and generated builds must not include employer names, internal projects, use-case counts, delivery outcomes, employer communities or employer-derived examples. Do not turn that work into an anonymised case study. Keep professional CV details behind the existing access controls. Public SEO and editorial content must use independent perspectives and clearly hypothetical examples.

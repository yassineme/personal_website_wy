# User publication rule

All website and CV changes must remain local for the user to modify and review.
The user approves changes and manually pushes/publishes them.
Never deploy, promote, push commits, change live hosting/environment settings,
or run production verification that submits forms as part of ordinary work.
Do not treat a request to change the website as permission to publish it.
Local previews and tests are allowed. Do not change the live site to roll back
an earlier deployment unless the user explicitly requests that live action.

# Website palette

Use the existing website charcoal (`--paper`), ivory (`--ink`) and muted grey
(`--muted`) palette for interface components. Do not introduce green, red or
other accent colours to markets panels, tooltips or quote indicators. Use the
existing directional arrows and labels to distinguish market movement.
